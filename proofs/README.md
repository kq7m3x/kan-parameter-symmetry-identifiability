## Notes on writing proofs here

- Use `$...$` / `$$...$$` — GitHub renders LaTeX math natively in `.md` files.
- One result per file (e.g. `01-exact-symmetries.md`); keep this README as the index.
- Classical results (e.g. B-spline properties from de Boor) are cited, not re-proved as new.
