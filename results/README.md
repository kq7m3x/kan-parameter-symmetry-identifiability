# Results

Experimental results, one folder per stage of the study. Figures are shared across the paper, this repo, and the research site.

| Folder | Stage |
|---|---|
| `00-foundation/` | Basis checks, gradient checks, function fitting |
| `01-exact-symmetries/` | Exact symmetries and the Hessian null space |
| `02-approximate-symmetries/` | Grid-induced symmetry breaking and small Hessian eigenvalues |
| `03-symbolic-extraction/` | Formula differences across seeds |

Each folder has:
- `figures/` — plots used in the paper or on the site
- `raw/` — the numbers behind them (e.g. `.csv`, `.json`), with the seed and configuration that produced them
